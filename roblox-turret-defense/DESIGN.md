# 🍀 스타 운빨·조합 터렛 디펜스 — 게임 설계서

> **한 줄 소개** — 4명이 P1~P4 **라인을 하나씩 맡아**, 미네랄로 터렛을 **랜덤 뽑기**하고 같은 터렛 2개를 **합성해 신화까지 진화**시키며, **중앙 넥서스**로 몰려오는 20웨이브와 **공성 보스**를 함께 막는 협동 디펜스.
> 장르: 랜덤 타워 디펜스(RTD) × 머지(합성 진화) × 4인 협동 × 로그라이크 유물

---

## 1. 왜 이 게임인가 (수익화 관점)

| 요소 | 이 게임에서 하는 일 | 왜 돈이 되는가 |
|---|---|---|
| **뽑기** | 미네랄로 터렛 랜덤 소환 (일반 62% ~ 신화 0.5%) | "한 번만 더" 심리 → 소모성 개발자 상품 |
| **합성** | 같은 등급·같은 종류 2개 → 상위 등급 (★3까지) | 슬롯 압박 + **자동 합성 패스** 구매 유도 |
| **4인 협동** | 라인 분담 + 공용 넥서스 + 공용 보스 | 친구 초대 → 자연 유입·체류 시간 증가 |
| **웨이브 압박** | 20웨이브, 5웨이브마다 보스 공성 | 2배속 패스·부활권·전설 확정권 |
| **수집** | 5등급 × 2종 = 10종 | VIP 추가 슬롯·도감 완성 욕구 |

로블록스 유저 100명 중 1~2명이 100~500 로벅스를 쓰는 구조를 전제로,
**첫 구매 문턱은 99~199 로벅스(2배속·자동합성)**, 고래용은 **전설 확정 뽑기권**으로 받는 2단 설계.

## 2. 핵심 루프 (30초 안에 손에 익는 순서)

```
① 내 라인(P1~P4) 확인 → [🔮 랜덤 뽑기] 로 빈 패드에 터렛 소환
        ↓
② 같은 등급·같은 종류 2개 → [⚡ 합성 진화] (탭 · 드래그 · 원터치)
        ↓
③ 웨이브 클리어 → 파티 공용 가스 획득
        ↓
④ [⚔ 공격력] · [⚡ 공속] 강화 (파티 전체 적용)
        ↓
⑤ 5웨이브마다 울트라리스크 → 넥서스 광장 공성전
        ↓
⑥ 보스 처치 → [유물 3지선다] → 20웨이브 생존 = 승리
```

- **실패 조건**: 적이 넥서스에 도달해 넥서스 HP 30이 0이 되면 패배.
- **한 판 길이**: 4인 협동 기준 8~12분.
- **조작**: 터렛 탭 = 선택 · 같은 터렛 탭/드래그 = 합성 · 하단 버튼 = 뽑기·합성·강화·지원.

## 3. 4인 협동 구조 (LoL·Fight of Characters식)

```
   [P1 게이트]   [P2 게이트]   [P3 게이트]   [P4 게이트]
        │             │             │             │
   ▓▓▓ 라인1 ▓▓▓  ▓▓▓ 라인2 ▓▓▓  ▓▓▓ 라인3 ▓▓▓  ▓▓▓ 라인4 ▓▓▓
   ▓ 터렛4+VIP1 ▓  ▓ 터렛4+VIP1 ▓  ▓ 터렛4+VIP1 ▓  ▓ 터렛4+VIP1 ▓
        │             │             │             │
        └─────────────┴──────┬──────┴─────────────┘
                             ▼
                    ✦ 중앙 넥서스 (공용 HP)
                    · 보스는 이 광장에서 공성
                    · 4인 화력이 한 점에 모임
```

| 역할 | 하는 일 |
|---|---|
| **P1~P4 (사람)** | 각자 자기 라인 패드 4칸(+VIP 1칸)에서 뽑기·합성·판매, 개인 미네랄 관리 |
| **파티 공용** | 넥서스 HP · 가스 강화(공격력/공속) · 유물 효과 |
| **보스 구역** | 울트라리스크가 넥서스 광장에 정지해 2.4초마다 넥서스 피해 → **전 라인 터렛이 사거리 안에서 협공** |
| **지원 작전** | 궤도 폭격(미네랄 120, 전장 타격) · 넥서스 수리(미네랄 90, HP +5) |

- 사파리 3D 미니판은 **사람 1명 + AI 아군 3명(루나·카이·미라)** 으로 같은 4인 구도를 재현합니다. AI는 자기 라인에서 자동으로 뽑기·합성합니다.
- 로블록스판은 접속 순서대로 P1~P4 자동 배정, 최대 4인.

## 9. 그래픽 · 연출 원칙

- **터렛**: 금속 받침대 → 360° 부드러운 추적 회전 → 발사 시 **포신 반동** → 등급별 네온 코어·오라 링·색상.
- **전투**: 총알 트레이서 · 미사일 궤적 · 시즈 곡사포 · 아콘/신화 레이저 빔 · 피격 플래시 · 폭발 파티클 · 확산 링.
- **전장**: SF 메탈릭 데크(격자 패널) · 라인별 네온 레일과 컬러 라이트 · 스폰 게이트 아치 · 중앙 **넥서스 회전 크리스탈 + 3중 링 + 에너지 빔** · 안개·조명 대비.
- **HUD**: 스타크래프트 콘솔 감성 메탈 플레이트, 등급 색상, 4인 파티 칩, 합성 가능 펄스.

## 10. 4인 협동 로블록스 구현 메모

- 접속 순서로 라인 자동 배정(`player:SetAttribute("Lane", n)`), 5번째 접속자는 입장 제한.
- 터렛·적은 **서버 권한**으로만 생성/피해 계산 → 치트 방지.
- 상태는 서버가 4Hz로 `TD_State` 로 각 플레이어에게 개인화 전송(내 미네랄·내 패드·파티 현황).
- 보스 공성·넥서스 HP는 공용, 유물은 **먼저 고른 사람의 선택이 파티 전체 적용**.
- 밸런스 목표: 4인 기준 20웨이브 클리어 30~40%, 무과금도 12~15웨이브 도달.
