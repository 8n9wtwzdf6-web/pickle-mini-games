## 2. 게임 흐름 (30초 안에 손에 익는 순서)

1. 접속 → **P1~P4 라인 자동 배정** (최대 4인)
2. 내 라인 패드에 **🔮 뽑기**(미네랄 18) → 같은 등급·같은 종류 2개를 **⚡ 합성**해 일반→희귀→영웅→전설→신화→★3
3. 웨이브 클리어 → **가스** 획득 → 파티 공용 **공격력·공속** 강화
4. 5·10·15·20 웨이브 **울트라리스크** → 공성 → 처치 시 **유물 3~4지선다**
5. 넥서스 HP가 0이 되면 **12초 부활 창구**가 열립니다 (보관 부활권 1탭 / 그 자리에서 25 R$ 구매)
6. 20웨이브 생존 = 승리 → **20초 뒤 자동으로 새 판** (나갔다 들어올 필요 없음)
