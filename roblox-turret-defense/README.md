# 🌌 터렛 디펜스 v3 — Roblox 우주 5아레나 키트

거대한 우주 공간에 **5개 종족의 부유 아레나**가 떠 있습니다.
플레이어는 자기 섬의 **자유 건설 그리드**에 원하는 위치로 터렛을 세워 미로를 만들고,
**40단계 × 100마리(일반 99 + 2배 영웅 1)** 를 막은 뒤,
마지막엔 **우주 정중앙의 오메가 파괴신**에게 5개 팀이 동시에 화력을 퍼부으며 **실시간 딜량 1~5위**를 다툽니다.

- **5대 종족** 👤휴먼 · 🛡️메카 · 🔮아케인 · 🧬바이오 · 🛸드론 (종족별 넥서스 + 특성)
- **2모드 변형** 모든 유닛 `🔄 모드 전환` (외형·공격 이펙트·스킬 변경) + `✨ 액티브 스킬`
- **이종족 융합** 서로 다른 종족 3+2 → 고유 융합 유닛 5종 + 시너지 버프
- **3대 맵 테마** 🌌 우주 요새 · 🏰 판타지 성채 · 🏙️ 사이버펑크
- **경쟁전 맞춤 유료화** 패스 6종 · 상품 11종 (과충전·방해·지원소환·융합 마스터)
- **저장·리텐션 유지** DataStore · 7일 출석 · 체류 보상 · 일일 퀘스트 · 영구 강화

## 2. 게임 흐름

1. 접속 → 인트로에서 **테마(3종)·종족(5종)** 선택 → **⚔ 전투 시작**
2. 내 아레나의 **빈 타일**을 눌러 원하는 위치에 터렛 건설 (미로 전략)
3. 같은 종족·모드·등급 2기 → **⚡ 합성** (일반 → 희귀 → 영웅 → 전설 → 신화 → ★3)
4. 유닛을 눌러 **🔄 모드 전환**(6초 쿨) · **✨ 스킬** · **↔ 이동** · **💎 판매**
5. 다른 종족 유닛 3+2 → **🧬 융합** → 고유 융합 유닛 + 아레나 버프
6. 5·10·15… 스테이지 클리어마다 **유물 3~4지선다**
7. 넥서스 HP 0 → **12초 부활 창구** (보관 부활권 1탭 / 25 R$ 즉시)
8. 40단계 완주 → **우주 정중앙 오메가 파괴신 레이드** → 5팀 딜량 1~5위 경쟁
9. 보스 격파(또는 150초 실패) → **20초 뒤 자동 새 판**
